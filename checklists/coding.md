# 代码编写质检清单

## 适用场景
写代码、改代码、部署、debug、实现功能

## 清单（编码完成后逐条检查，全部 pass 才算交付）

### 1. 安全检查
**判断：** 是否存在安全隐患？
- fail 条件 → 必须修正：
  - 硬编码密钥/token/密码
  - 未校验的用户输入直接执行
  - 暴露敏感端口或调试接口
  - SQL注入/命令注入风险

### 2. 边界与异常
**判断：** 关键函数是否有边界条件处理和异常捕获？
- pass → 有 try-catch 或等效机制，处理了空值、超时、错误返回
- fail → 缺少异常处理 → 补充后再交付

### 3. 运行验证
**判断：** 代码是否能实际运行通过？
- pass → 已通过 curl/测试脚本/实际调用验证
- fail → 未验证 → 必须验证后再交付（AGENTS.md 强制规则）

### 4. 变更范围
**判断：** 是否只修改了该修改的文件？
- pass → 变更范围与任务需求一致
- fail → 意外修改了无关文件 → 撤销无关变更

## 输出要求

- 交付时附加：`[质检: coding ✓]`
- 部分通过：`[质检: coding 3/4 ✓ 边界处理待补充]`
