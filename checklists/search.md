# 信息搜索质检清单

## 适用场景
搜索信息、查资料、找数据、查最新动态

## 清单（输出前逐条检查，全部 pass 才能发送）

### 1. 来源分级
**判断：** 每条信息是否标注了来源可信度？
- pass → 所有信息都有来源等级
- fail → 无来源标注 → 按以下分级补充：
  - **[一手]** 官方文档、官方公告、原始数据
  - **[二手]** 顶级媒体报道、行业报告、权威博客
  - **[三手]** 社区帖子、评论、二次转载

### 2. 时效检查
**判断：** 数据是否有时间戳？是否可能已过期？
- pass → 每条数据附带时间或标注"截至X日期"
- fail → 无时间信息且内容有时效性 → 标注 [时效未知]

### 3. 多源交叉
**判断：** 关键事实是否至少有 2 个独立来源？
- pass → 关键事实有多源确认
- fail → 关键事实仅单一来源 → 必须标注 [单一来源，未交叉验证]

### 4. 事实观点分离
**判断：** 是否把观点当事实呈现了？
- pass → 事实和观点明确区分，观点标注了出处
- fail → 观点混在事实中 → 改写为："X 认为..."、"Y 的观点是..."

## 输出要求

- 质检通过：`[质检: search ✓]`
- 部分通过：`[质检: search 3/4 ✓ 多源交叉待补充]`
