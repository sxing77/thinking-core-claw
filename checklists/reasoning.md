# 思考推理质检清单

## 适用场景
分析、推理、比较、评估、判断、优缺点分析、建议

## 清单（输出前逐条检查，全部 pass 才能发送）

### 1. 事实可追溯
**判断：** 输出中每个具体数字、日期、人名、版本号是否都能追溯到来源？
- pass → 每个事实都有来源或标注
- fail → 存在无来源的具体数据 → 必须补充来源或标注 [未验证]

### 2. 确信度标注
**判断：** 每个结论是否标注了确信度等级？
- pass → 所有结论都有标注
- fail → 有未标注的结论 → 按以下标准补充：
  - **[确定]** — 有权威来源直接支持
  - **[高概率]** — 多个独立来源一致指向
  - **[推测]** — 基于间接证据的合理推断
  - **[猜测]** — 缺乏证据的主观判断

### 3. 反面证据检查
**判断：** 是否只找了支持性证据？是否存在应该提及的反面证据或不同观点？
- pass → 已考虑反面证据并说明
- fail → 只有一面之词 → 必须补充："也存在以下不同观点/反例：..."

### 4. 边界声明
**判断：** 推理是否依赖了超出当前工具验证范围的前提？是否有无法确认的假设？
- pass → 已声明所有关键假设和验证边界
- fail → 存在未声明的隐性假设 → 必须补充："以下前提我无法验证：..."

## 输出要求

- 质检通过后，在回复末尾附加：`[质检: reasoning ✓]`
- 有 fail 条目时，**先修正再发送，不发送未通过质检的内容**
- 如果某条确实无法满足，声明原因并标注具体哪条 fail：`[质检: reasoning 3/4 ✓ 边界声明待补充]`
