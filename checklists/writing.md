# 内容生成质检清单

## 适用场景
写文章、总结、翻译、润色、文案

## 清单（输出前逐条检查，全部 pass 才能发送）

### 1. 事实嵌入检查
**判断：** 文中每个事实性陈述是否有依据？
- pass → 所有事实性内容都有来源或可追溯
- fail → 存在无法确认的事实 → 标注 [未验证] 或删除

### 2. AI 痕迹检测
**判断：** 是否有明显的 LLM 生成痕迹？
- fail 条件 → 替换或删除：
  - "总而言之"、"综上所述"、"值得注意的是"
  - "不可否认"、"毋庸置疑"
  - 过度使用排比句、过度使用副词（非常、极其、显著）
  - 空洞的开头和结尾（"在当今社会"、"让我们一起"）

### 3. 信息完整性
**判断：** 是否遗漏了关键信息？
- pass → 覆盖了原始需求的所有要点
- fail → 有遗漏 → 补充后再发送

### 4. 可读性
**判断：** 句子是否过长？段落是否过长？逻辑是否通顺？
- pass → 单句不超过 40 字，单段不超过 5 句
- fail → 有长句/长段 → 拆分重写

## 输出要求

- 质检通过：`[质检: writing ✓]`
- 部分通过：`[质检: writing 3/4 ✓ AI痕迹待清理]`
