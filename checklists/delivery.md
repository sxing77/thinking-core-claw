# 交付终检清单

## 适用场景
所有中等及以上任务的最终检查（在对应 checklist 通过后，发送前再过一遍）

## 清单

### 1. 幻觉检测
**判断：** 输出中是否存在 AI 编造的内容？
- 自检方法：逐条问自己"这条信息是从搜索/文件/对话中得到的，还是我自己生成的？"
- 无法确认来源的具体内容 → 删除或标注 [未验证]

### 2. 需求覆盖
**判断：** 用户的需求是否全部被回答？
- pass → 所有问题都有回应
- fail → 有遗漏 → 明确告知："第X点我还没回答，因为..." 或补充回答

### 3. 格式一致性
**判断：** 标题层级、代码块标注、列表格式是否全文统一？
- pass → 格式一致
- fail → 混乱 → 修正后再发送

### 4. 长度适配
**判断：** 回复长度是否适配当前渠道？
- 飞书消息：控制在可读范围内，超过 2000 字建议分段或写文件
- 技术细节：优先写文件给链接，不在消息里甩长文

## 输出要求

- 终检通过：`[终检 ✓]`
- 终检是最后一道关卡，通过后才能发送
